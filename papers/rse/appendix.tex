\section{Reproducibility Checklist}
\label{app:repro}

This appendix follows the NeurIPS reproducibility checklist structure.

\subsection{Scope of reproducibility}

Claims supported by automated harness runs in this repository:
(1)~RMC-Bench transfer and retrieval scores;
(2)~recall ablation precision/recall/noise;
(3)~WikiSkill-comparable four-arm comparison;
(4)~session paired study lift;
(5)~synthetic scaling table.
Claims from dogfood (\texttt{EXPERIMENTS.md}) are directional measurements on one user's store.

\subsection{Algorithm}

The full RSE loop is implemented in the \texttt{rmc} Python package:
\texttt{recall}, \texttt{reflect}, \texttt{compact}, \texttt{tune}, and \texttt{eval-recall} subcommands.
Design specification: \texttt{DESIGN.md}.

\subsection{Dataset and benchmarks}

\begin{itemize}
  \item \textbf{RMC-Bench:} \texttt{evals/rmc-bench.yaml} (25 hand-written cases).
  \item \textbf{WikiSkill-comparable:} \texttt{evals/wikiskill-bench.yaml} (10 tasks, 5 domains).
  \item \textbf{Upstream SealQA:} \texttt{evals/upstream/sealqa-test.jsonl} (111 tasks, HF import).
  \item \textbf{MemGPT proxy:} \texttt{evals/memgpt-nested-kv.yaml} (8 nested-KV cases).
  \item \textbf{Session pairs:} \texttt{evals/session-pairs.yaml} (5 follow-up pairs).
  \item \textbf{Recall ablations:} fixture store under \texttt{evals/fixtures/recall-store/}.
\end{itemize}

\subsection{Hyperparameters}

\begin{itemize}
  \item Grading agent: Codex (\texttt{gpt-5.6-sol}).
  \item Samples per case: 3 (majority vote).
  \item Compression ratio target $\rho = 0.7$.
  \item Replay pass threshold: 100\%.
\end{itemize}

\subsection{Computational resources}

Full Codex suite (\texttt{run\_all\_experiments.py --agent codex --samples 3}) requires authenticated Codex CLI and approximately 30--60 minutes wall time depending on API latency.
Preflight validation (\texttt{validate\_agent\_harness.py}) uses $\sim$4 Codex calls.

\subsection{Code and data availability}

\begin{itemize}
  \item Repository: \url{https://github.com/yiheinchai/rmc}
  \item Results: \texttt{papers/rse/results/submission-latest.json}
  \item Figures: \texttt{papers/rse/figures/}
\end{itemize}

\subsection{Experimental setup}

\begin{verbatim}
pip install -e ".[dev]"
python3 scripts/validate_agent_harness.py --agent codex
python3 scripts/run_all_experiments.py --agent codex --samples 3
python3 scripts/generate_submission_report.py
python3 scripts/generate_paper_figures.py
cd papers/rse && make
\end{verbatim}

\subsection{Statistical significance}

WikiSkill and upstream runs report bootstrap 95\% confidence intervals and paired bootstrap tests vs.\ full-inject (\texttt{rmc/stats.py}).
Default runs use 3 samples; increase with \texttt{--samples N} for tighter CIs.

\subsection{Known limitations of reproduction}

\begin{itemize}
  \item Codex CLI authentication required; results vary with model version.
  \item Claude cross-check (\texttt{scripts/run\_claude\_crosscheck.sh}) requires separate \texttt{claude} authentication.
  \item WikiSkill subset is curated; full upstream splits not yet wired.
\end{itemize}
